# Slate

DJ Nurre's personal site: an executive producer and showrunner who builds AI agents.

**[r10forthewin.github.io/slate](https://r10forthewin.github.io/slate/)**

Twenty years running television, now building the tools. The site lays out the slate of agents, what each one does, and links to its live demo and public code, including [Artie](https://github.com/R10ForTheWin/artie), [Rundle](https://github.com/R10ForTheWin/rundle-app), [WallSight](https://github.com/R10ForTheWin/wallsight-demo) and [Oreo's Map Quest](https://github.com/R10ForTheWin/map-quiz).

A single static `index.html`, hosted on GitHub Pages.
